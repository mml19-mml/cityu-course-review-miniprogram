# CityU Course Review Miniprogram
WeChat Mini Program source code for CityU course rating and review.

## Project Overview
This is a WeChat Mini Program prototype, designed for CityU students to browse, search and share real course reviews.
Users can check course information, read feedback from other students and submit their own course ratings.

## Features
- Course list & search function
- Course review browsing and submission
- Student-oriented course evaluation system

## Tech Stack
- Frontend: WeChat Mini Program native framework (WXML / WXSS / JS / JSON)
- Database: Supabase
- Design & product: UX research, UI design, product planning

## Notes
This repository contains the source code of the WeChat Mini Program.
It cannot be directly previewed in a browser. To run this demo, import the project into WeChat Developer Tools.
